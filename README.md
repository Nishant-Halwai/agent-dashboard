# AgentHub - AI Agent Dashboard & Landing Page

AgentHub is a professional, high-performance landing page and dashboard designed to showcase a suite of intelligent AI agents. Built with modern web technologies, it features a premium aesthetic with glassmorphism effects, dynamic animations, and a responsive layout.

## 🚀 Features

- **Premium Design**: Modern dark theme with a glassmorphism design system.
- **Dynamic Animations**: Smooth parallax effects, 3D tilt interactions on cards, and scroll-triggered fade-ins.
- **Interactive Showcase**: A grid of specialized AI agents with interactive mouse-following hover effects.
- **Legal Infrastructure**: Dedicated, styled pages for **Privacy Policy** and **Terms of Service**.
- **Responsive Layout**: Optimized for all screen sizes, from mobile devices to large desktops.
- **Performance Focused**: Minimal dependencies and optimized asset loading via Vite.

## 🛠️ Technology Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: CSS3 (Vanilla)
- **Build Tool**: Vite v7
- **Typography**: Inter (Google Fonts)

## 📁 Project Structure

## 📦 Installation & Setup

1. **Clone the repository** (or download the source code).
2. **Install dependencies**:
   ```powershell
   npm install
   ```
3. **Run the development server**:
   ```powershell
   npm run dev
   ```
4. **Build for production**:
   ```powershell
   npm run build
   ```

## 🎨 Design Philosophy

AgentHub prioritizes **Visual Excellence**. The UI uses balanced gradients, subtle micro-animations, and a consistent spacing system to create a premium feel that wows users at first glance.
